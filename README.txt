TEACHER'S DAY WEBSITE - MADAM RANI

FILES:
- index.html = main website
- style.css = design and animations
- script.js = music, scrolling and falling petals
- photos/photo1.jpg, photo2.jpg, photo3.jpg = replace these with your own photos
- music/teacher-day.mp3 = put your chosen MP3 here

HOW TO ADD PHOTOS:
1. Put your three photos inside the "photos" folder.
2. Rename them exactly:
   photo1.jpg
   photo2.jpg
   photo3.jpg
   PNG files also work if you change the filename in index.html.
3. Open index.html to preview.

HOW TO ADD MUSIC:
1. Put an MP3 file in the "music" folder.
2. Rename it exactly: teacher-day.mp3
3. Open the website and tap the Music button.

IMPORTANT FOR QR CODE:
A QR code can only open the website if the website is hosted online. Opening index.html from your phone/computer is useful for testing, but a QR code cannot magically host files. Upload this folder to a web host, then create a QR code for the published website URL.

The included QR code is only a placeholder-style instruction card and is NOT a live website QR code.
